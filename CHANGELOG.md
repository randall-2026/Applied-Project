# Changelog

All notable changes to the Judgment Gym project will be documented in this file.

## [0.1.0-baseline] - 2026-06-13

### Added
- Established baseline project repository for Judgment Gym.
- Added main React prototype file: `JudgmentGym.jsx`.
- Added project presentation/report artifact: `JudgmentGym_Report.pptx`.
- Added README with setup and run instructions.
- Added architecture notes describing the current single-file React prototype.
- Added risk log and known issues log for project tracking.
- Added baseline check-in documentation and smoke-test evidence placeholder.

### Implemented
- Decision creation workflow.
- Commit-before-feedback workflow.
- Locked decision fields after commitment.
- Simulated adversarial critique generation.
- Outcome logging and reflection workflow.
- Basic analytics view.
- Practice scenario mode.

### Notes
- The current implementation is a client-side prototype.
- The AI critique is simulated locally and does not call an external API.
- No persistent backend storage is included in the baseline.
